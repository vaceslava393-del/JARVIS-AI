# JARVIS-AI — объединённый репозиторий

В этом репозитории находятся два независимых проекта JARVIS:

| Папка | Описание |
|---|---|
| `JARVIS-AI/` | Базовая версия проекта. Содержимое перенесено из `origin/main` без изменения файлов. |
| `chatAi/` | Расширенная версия JARVIS: FastAPI-сервер, веб-интерфейс, голосовой ввод и ответы, камера, компьютерное зрение и Android-клиент. |

## Что было сделано

- добавлен GitHub-репозиторий как `origin`;
- загружена и сохранена история базовой версии проекта;
- объединены две независимые Git-истории;
- базовая версия размещена в `JARVIS-AI/` без изменения содержимого;
- второй проект размещён отдельно в `chatAi/`;
- секретный `.env`, виртуальное окружение, логи и каталоги сборки исключены из Git;
- в `chatAi/README.md` добавлена подробная инструкция по установке библиотек, запуску сервера и сборке APK.

JARVIS AI с картинкой

1. Установите зависимости: pip install fastapi uvicorn httpx python-dotenv opencv-python ultralytics
2. Если используете Groq, создайте рядом с JARVIS_AI.py файл .env и добавьте строку: GROQ_API_KEY=ВАШ_КЛЮЧ
3. Запустите: python JARVIS_AI.py
4. Откройте в браузере: http://127.0.0.1:9014

Фоновая картинка уже лежит в static/jarvis_wallpaper.png. Не перемещайте её отдельно от папки static.
